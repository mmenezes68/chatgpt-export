# Ata 020 — Plano de migração para microserviços Python e estrutura bilíngue ABNT
**Data:** DATE_PLACEHOLDER  
**Participantes:** Marcos Menezes, Assistente  
**Local:** Projeto chatgpt-export (iMac)

## 1. Contexto
Evolução do pipeline shell+Pandoc+LaTeX para arquitetura **Python** (CLI/serviços) mantendo **legado** e **bilíngue (PT/EN)** conforme **ABNT**.

## 2. Decisões
- D1: Python 3.11+, cross-platform.
- D2: CLI (Typer) reutilizável por FastAPI/Streamlit.
- D3: Manter scripts shell como fallback.
- D4: Estrutura de obra bilíngue com TOC ABNT.
- D5: PDF via Pandoc/LaTeX orquestrado por pypandoc.
- D6: Qualidade: pytest, pre-commit (ruff/black), loguru.

## 3. Ações
1) **Bootstrap** repositório Python (microservices/{core,cli,api}, pyproject).  
2) **Modelos** Pydantic para obra/capítulos e ordenação canônica (Intro → Cap.1..6 → Referências → Anexos).  
3) **Templates**: portar `relatorio-abnt-usp.tex` e `abnt-header.tex`.  
4) **Comandos CLI**: `build:pt`, `build:en`, `build:all`, `check`.  
5) **Watcher** (watchdog) para rebuild automático.  
6) **Validação ABNT** mínima (sumário, páginas, referências).  
7) **Docs**: README de uso e migração do legado.
