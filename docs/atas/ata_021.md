## 1. Contexto
Dando sequência à migração para microserviços Python, esta ata define o **microserviço de onboarding/configuração** que apresenta o sistema ao usuário, explica as limitações legais (direitos autorais) e permite configurar o projeto **via CLI interativa** ou **arquivo de parâmetros** (YAML/JSON). As escolhas devem ser persistidas em `content/<obra>/config/params.yml` para uso pelos demais serviços.

## 2. Decisões
- **D1:** Arquitetura por domínio em `microservices/` (onboarding, core/abnt, core/toc, cli), consumindo conteúdo em `content/<obra>/{pt,en}`.  
- **D2:** Relatório **bilíngue obrigatório** (PT/EN) com a **mesma ordem** de capítulos.  
- **D3:** Onboarding em `microservices/onboarding/cli.py` com `--params params.yml` opcional; se ausente, pergunta interativamente e salva.  
- **D4:** **Aviso legal:** referência à **Lei nº 9.610/1998 (Brasil)** — o sistema não distribui conteúdo protegido; processa apenas arquivos fornecidos pelo usuário para fins de estudo/pesquisa.  
- **D5:** Boas práticas: logs, validações, idempotência, testes de fumaça e comandos `make`.  
- **D6:** Registro formal **sempre via kit de atas**.
