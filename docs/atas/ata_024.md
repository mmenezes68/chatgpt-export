# Ata 024 — Planejamento do Pipeline ABNTex2 e Microserviços
**Data:** 2025-09-01  
**Participantes:** Marcos A. Menezes, Agente GPT  
**Local:** Remoto / Documentação interna  

## 1. Contexto
Após consolidar as atas anteriores (019–022), foi definido o caminho para criar um pipeline robusto que compile relatórios em PDF conforme a norma ABNT usando a classe abntex2. O projeto precisa padronizar as seções dos relatórios (Ideias Principais, Conceitos‑Chave, Questões de Reflexão, Trechos Relevantes), migrar scripts legados em zsh para um pipeline em Python multiplataforma e manter um kit de atas para garantir rastreabilidade entre diferentes chats e obras. Essa ata registra o plano de arquitetura e as decisões para iniciar a implementação.

## 2. Decisões
D1: Adotar a classe `abntex2` com opções `12pt,oneside,a4paper,openany` na conversão Markdown → LaTeX via Pandoc.  
D2: Incluir um cabeçalho (`header_abntex2.tex`) com os pacotes `microtype`, `xurl` e `etoolbox`; definir ganchos para neutralizar `\newpage`/`\clearpage` em `longtable` e ajustar `\emergencystretch` e penalidades de hifenização.  
D3: Construir um script `build.py` em Python que gere o `.tex`, aplique saneamento (remover `\\` após `\newpage`/`\clearpage` e limpar longtables), compile com XeLaTeX duas vezes e gere um relatório de QA.  
D4: Garantir que cada capítulo de leitura siga o modelo de quatro seções (Ideias Principais, Conceitos‑Chave, Questões de Reflexão, Trechos Relevantes).  
D5: Manter o kit de atas (atas.sh) como fonte única de criação, fixação, indexação e versionamento das atas.  
D6: Próximo passo será a elaboração de microserviços independentes (`abnt.py`, `toc.py`, `sanitize.py`) para build e validação de ABNT, integrados ao pipeline principal.
