## 1. Contexto
Foi criado e versionado o script `sanitize_md.sh` para normalizar cabeçalhos incorretos nos arquivos `.md` consolidados.  
Problemas recorrentes, como títulos literais (`## 00_intro.md`) e nomenclaturas desalinhadas, impactavam diretamente o sumário e a formatação dos relatórios em PDF no padrão ABNT/USP.  

## 2. Decisões
- D1: Tornar obrigatório o uso de `sanitize_md.sh` antes de qualquer compilação de relatórios.  
- D2: Incluir o script como etapa do pipeline de geração (`gera_pdf_abnt.sh`).  
- D3: Atualizar a documentação (`metodologia.md`) para registrar essa etapa como requisito oficial.
