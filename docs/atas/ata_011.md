## 1. Contexto
Persistem problemas estruturais nos PDFs (cabeçalhos herdados de nomes de arquivos, “Capa” como seção do corpo, TOC com níveis incorretos e inconsistências PT/EN). É necessário alinhar geradores, sanitização e template ABNT/USP.

## 2. Decisões
- D1: Consolidar capítulos com títulos sem vestígios de nome de arquivo; capítulos como H1 e seções internas como H2.  
- D2: Capa e folha de rosto apenas no template LaTeX (fora do corpo do Markdown).  
- D3: YAML mínimo por obra (título, autor, orientador, instituição, local, ano, língua).  
- D4: Sanitização obrigatória (PT/EN) via `sanitize_md.sh` após montar o consolidado.  
- D5: Pré-flight de caracteres especiais via `preflight_md.sh` antes do Pandoc.  
- D6: Geração dupla PT/EN com `gera_pdf_abnt.sh`, mantendo o mesmo template.  
- D7: Auditoria com `audita_obra.sh` antes do build final.
